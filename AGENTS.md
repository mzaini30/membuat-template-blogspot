MENGOLAH TEMPLATE BLOGSPOT

- Jangan membuat gambar (GenerateImage) di folder ini karena nanti pasti nggak tampil. Kan yang akan disalin ke Blogspot itu hanya satu file Template.xml. Maka, gambar di local pasti nggak akan masuk. Alternatifnya, kalau mau ada gambarnya, gunakan yang sudah ada di internet saja
- PENTING : Buat komponen-komponen pada Template.xml ini mengikuti aturan-aturan yang ada di Aturan/bagian/ sehingga semua komponen itu editable di Tata Letak Blogspot. Misalnya aja, komponen alamat rumah. Nah, itu menggunakan bagian text.xml misalnya, sehingga bisa diedit value-nya di Tata Letak Blogspot
- Bantu aku merancang template Blogspot yang hasilnya nanti di Template.xml
- Folder Aturan/ berisi semua aturan yang membentuk suatu template Blogspot
- Semua komponen Blogspot tersedia di Aturan/bagian/
- Folder Aturan/contoh/ berisi dua file template Blogspot yang banyak orang-orang gunakan dan recommended
- File Aturan/meta.xml itu tentang struktur Meta di <head/> pada template Blogspot
- File Aturan/template.html adalah contoh bentuk template Blogspot
